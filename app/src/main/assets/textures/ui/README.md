# UI Assets

## Cấu trúc thư mục:

- `buttons/` - Buttons (normal, pressed, disabled states)
- `panels/` - Panels và windows (inventory, dialog, menu)
- `icons/` - Icons nhỏ (health, mana, stats)
- `hud/` - HUD elements (health bars, joystick)

## Naming convention:

- `[element]_[state].png`
- States: `normal`, `pressed`, `disabled`, `hover`

## Examples:

- `btn_normal.png`
- `btn_pressed.png`
- `health_bar.png`
- `inventory_panel.png`

## Recommended sizes:

- Buttons: 128x64 pixels
- Icons: 32x32 pixels
- Panels: 256x256+ pixels

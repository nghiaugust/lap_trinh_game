# NPC Characters

## Các loại NPCs:

- `merchant/` - Thương gia
- `guard/` - Lính gác
- Có thể thêm: `blacksmith/`, `innkeeper/`, `quest_giver/`

## Naming convention:

- `[npc_type]_[action].png`
- Actions: `idle`, `talk`, `work`

## Examples:

- `merchant_idle.png`
- `merchant_talk.png`
- `guard_idle.png`
- `blacksmith_work.png`

## Recommended size: 64x64 pixels

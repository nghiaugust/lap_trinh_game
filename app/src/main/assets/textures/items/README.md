# Item Assets

## Cấu trúc thư mục:

- `weapons/` - Vũ khí (swords, axes, bows)
- `armor/` - Giáp (helmets, chest, shields)
- `consumables/` - Đồ tiêu hao (potions, food)
- `treasures/` - Kho báu (coins, gems)

## Naming convention:

- `[material]_[item_name].png`
- Materials: `iron`, `steel`, `magic`, `wooden`, `leather`

## Examples:

- `iron_sword.png`
- `health_potion.png`
- `leather_helmet.png`
- `gold_coin.png`

## Recommended size: 32x32 hoặc 64x64 pixels

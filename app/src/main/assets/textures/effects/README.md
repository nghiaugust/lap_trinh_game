# Visual Effects Assets

## Cấu trúc thư mục:

- `particles/` - Particle effects (fire, smoke, sparkles)
- `magic/` - Magic effects (fireball, lightning, heal)
- `combat/` - Combat effects (slash, blood, explosion)

## Naming convention:

- `[effect_name]_[frame].png`
- Frames: `01`, `02`, `03` cho animation

## Examples:

- `fire_01.png`
- `fireball_cast_01.png`
- `slash_effect.png`
- `explosion_03.png`

## Recommended size: 64x64 hoặc 128x128 pixels

## Note: Effects thường là transparent PNG với alpha channel

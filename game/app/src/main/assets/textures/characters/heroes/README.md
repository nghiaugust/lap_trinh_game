# Player Character Assets

## Cấu trúc thư mục:

- `idle/` - Sprites khi nhân vật đứng yên
- `walk/` - Animation khi nhân vật di chuyển
- `attack/` - Animation khi nhân vật tấn công
- `death/` - Animation khi nhân vật chết

## Naming convention:

- `player_[action]_[direction]_[frame].png`
- Directions: `front`, `back`, `left`, `right`
- Frames: `01`, `02`, `03`, ...

## Examples:

- `player_idle_front.png`
- `player_walk_left_01.png`
- `player_attack_front_02.png`
- `player_death_01.png`

## Recommended size: 64x64 hoặc 128x128 pixels

# Enemy Characters

## Các loại enemies:

- `orc/` - Quái orc cơ bản
- `skeleton/` - Quái xương
- `boss/` - Boss enemies (dragon, demon, etc.)

## Naming convention:

- `[enemy_type]_[action]_[frame].png`
- Actions: `idle`, `walk`, `attack`, `death`

## Examples:

- `orc_idle.png`
- `orc_walk_01.png`
- `skeleton_attack_01.png`
- `dragon_death_03.png`

## Recommended size: 64x64 cho enemies nhỏ, 128x128+ cho boss

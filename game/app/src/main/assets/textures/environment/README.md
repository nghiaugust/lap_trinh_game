# Environment Assets

## Cấu trúc thư mục:

- `tiles/` - Tiles cơ bản (grass, stone, water, dirt)
- `walls/` - Tường các loại (brick, stone, wood)
- `floors/` - Sàn nhà (stone, wood, carpet)
- `backgrounds/` - Background lớn (forest, dungeon, cave)
- `objects/` - Đối tượng môi trường (tree, rock, chest, door)

## Naming convention:

- `[type]_[variant].png`
- Variants: `01`, `02`, `03` cho nhiều biến thể

## Examples:

- `grass_01.png`
- `brick_wall.png`
- `tree_oak.png`
- `chest_closed.png`

## Recommended sizes:

- Tiles: 64x64 pixels
- Objects: 64x64 hoặc 128x128 pixels
- Backgrounds: 512x512+ pixels
